# .github

Org-wide defaults for [Forall Labs](https://forall-labs.ai).

| Path | What it does |
|---|---|
| `profile/README.md` | Renders on the organization landing page at [github.com/forall-labs](https://github.com/forall-labs) |

Community health files added here (`CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`,
issue and pull-request templates) apply to every repository in the organization that does not
provide its own.
